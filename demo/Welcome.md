# Welcome to Tickmark

This is a **demo**: a private copy of a few sample notes, just for you. Change anything you like; it's wiped after a while unused, and nobody else can see it.

Tickmark is a markdown notes app whose checklists can sync both ways with a CalDAV task list (Nextcloud, Radicale, tasks.org, Apple Reminders…). Sync is turned off here, but everything else works.

## Things to try

- [ ] Tick a box in the preview, or press `Ctrl+L` on a line in the editor
- [ ] Press `Ctrl+P` to jump to a note, or `Ctrl+Shift+P` for every command
- [ ] Open [[Tasks and states]] to see what a checklist can hold
- [ ] Open [[Formatting]] for markdown, embeds and code blocks
- [ ] Try a theme: Settings (the gear) → Appearance
- [ ] Turn on Vim mode or line numbers in Settings → Editor
- [ ] Open the ⋯ menu for this note's history, properties and templates

## Links

Wikilinks like [[Projects/Garden plan]] open other notes, and typing `[[` suggests them. The bottom of each note lists the notes that link to it.
